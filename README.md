## 📋 About

This is my personal portfolio website, built from scratch with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies. It showcases my background, technical skills, certifications, and social profiles.

---

## ✨ Features

- Custom animated cursor with smooth ring follow
- Scroll progress bar (purple → gold gradient)
- Typing animation on hero name
- Scroll-reveal animations on all sections
- Floating particle canvas (purple & gold)
- Active nav link highlighting on scroll
- Frosted glass navbar on scroll
- Hamburger menu for mobile
- Button ripple effects
- Welcome toast notification
- Fully responsive — mobile, tablet, desktop
